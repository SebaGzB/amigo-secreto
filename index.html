Cómo publicar y compartir gratis

1 Sube este archivo a Internet (Gratis, 30 seg)

Descarga este archivo HTML, cámbiale el nombre a index.html y arrástralo dentro de app.netlify.com/drop (o súbelo a GitHub Pages / Vercel). Obtendrás un enlace web real.

2 Comparte el enlace del grupo (#g=...)

Envía el enlace por WhatsApp. Cuando cada participante abra el link en su teléfono y escriba su nombre y opción de regalo, la app actualizará el enlace para que lo reenvíe al grupo.

3 Sortea y envía los enlaces secretos (#r=...)

Cuando todos estén anotados, presiona Realizar Sorteo y envíale a cada uno su enlace privado por WhatsApp. Cada enlace contiene únicamente el nombre y deseo de su amigo secreto.

¿Iniciar un grupo nuevo?

Se limpiará la lista actual y el enlace volverá a estar en blanco para crear otro sorteo.
