Conectar Firebase Realtime Database

Para que todos entren al mismo enlace a la vez y se vean en vivo, crea una base de datos gratuita en console.firebase.google.com (toma 2 minutos) y pega aquí tu bloque firebaseConfig:

// Ejemplo de lo que te entrega Firebase:
{
  "apiKey": "AIzaSy...",
  "authDomain": "tu-proyecto.firebaseapp.com",
  "databaseURL": "https://tu-proyecto-default-rtdb.firebaseio.com",
  "projectId": "tu-proyecto",
  "storageBucket": "tu-proyecto.appspot.com",
  "messagingSenderId": "123456789",
  "appId": "1:123456789:web:abcdef"
}

Nota: Para que el enlace funcione en los teléfonos de tus amigos, recuerda también pegar estas mismas credenciales dentro del archivo HTML antes de subirlo a GitHub.
